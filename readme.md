# HomeGrid Backup

**HomeGrid Backup** — нативный кроссплатформенный клиент для автоматического и ручного резервного копирования данных с сервера **HomeGrid Monitor** без использования браузера.

Поддерживает работу с графическим интерфейсом, в фоновом режиме с иконкой в системном трее и через консоль по расписанию на **Windows (7 / 10 / 11)**, **Linux (Ubuntu, Debian, MX Linux, antiX — 64-bit и 32-bit i386)**, **WSL2 / WSLg**, **macOS** и **Android**.

---

## Основные возможности

* **Автопоиск в локальной сети (LAN):** автоматическое сканирование активных подсетей с сохранением истории подключений.
* **Безопасность и изоляция секретов:** токены и PIN-коды (`LOGIN PIN`, `EDITOR PIN`) хранятся в системном хранилище (`keyring` / `libsecret` / Windows Credential Manager) или в защищённом файле `~/.backup_hgm/.env` (`chmod 0600`), а не в открытом `config.json`. Перед отправкой PIN выполняется двухэтапная проверка подлинности сервера.
* **Контроль целостности (CRC32 + SHA-256):** каждый скачанный ZIP-архив проверяется побайтно с буфером 1 МБ, рядом сохраняется контрольный файл `.sha256`. Встроенный инструмент анализа позволяет проверить все существующие архивы на диске.
* **Зеркалирование (Mirror):** автоматическое дублирование свежего архива и `.sha256` во вторую папку (например, на сетевой диск или внешний накопитель).
* **Кольцевая ротация копий:** хранение последних *N* архивов (по умолчанию 5) с возможностью защитить важные копии тегом `KEEP` и безопасным удалением устаревших файлов в Корзину.
* **Планировщик задач:** встроенная настройка ежедневного автозапуска через `schtasks` (Windows / WSL), `crontab` + `~/.config/autostart` (Linux) или `LaunchAgent` (macOS).
* **Адаптивный интерфейс и LITE-режим:** поддержка тёмной и светлой тем, автоматическое масштабирование под DPI экрана, а также ультралёгкий текстовый режим `LITE` для старых и маломощных ПК.

## Установка и запуск

Готовые сборки для всех платформ доступны в разделе **[Releases](../../releases)**.

### 1. Windows (7 / 10 / 11, x86 / x64)
1. Скачайте архив сборки для Windows со страницы **Releases** (или установщик `HomeGridBackup_Setup.exe`).
2. Распакуйте в любую папку и запустите **`HomeGridBackup.exe`**.
3. Для фонового запуска используйте `HomeGridBackup.exe --hidden`, для консольного — `HomeGridBackup.exe --cli`.

### 2. Ubuntu / Debian / Linux (64-bit x86_64)
1. Скачайте **`homegrid-backup-ubuntu-x86_64.7z`** со страницы **Releases** и распакуйте:
   ```bash
   7z x homegrid-backup-ubuntu-x86_64.7z
   chmod +x homegrid-backup install_shortcut.sh
   ```
2. Запустите программу:
   ```bash
   ./homegrid-backup
   ```
3. *(Опционально)* Создайте ярлык в меню приложений и на Рабочем столе:
   ```bash
   ./install_shortcut.sh
   ```

### 3. MX Linux / Debian / Старые ПК (32-bit i386 / i686)
Специальная сборка на базе `glibc 2.27` с поддержкой процессоров `i686` без AVX, совместимая с **MX Linux 32-bit**, **antiX**, **Debian 10+**, **Ubuntu 18.04+**, **Puppy Linux**:
1. Скачайте **`homegrid-backup-linux-i386-legacy.7z`** со страницы **Releases** и распакуйте:
   ```bash
   7z x homegrid-backup-linux-i386-legacy.7z
   chmod +x homegrid-backup install_shortcut.sh
   ./homegrid-backup
   ```

### 4. Запуск из исходного кода (Python 3.8+)
```bash
git clone https://github.com
cd HomeGridBackup
python3 main.py --gui
```
*(При первом запуске из исходников недостающие библиотеки `pillow`, `pystray`, `keyring`, `send2trash` устанавливаются автоматически).*

## Параметры командной строки (CLI)

| Флаг | Описание |
| :--- | :--- |
| `--gui` | Запуск графического интерфейса (режим по умолчанию при наличии дисплея). |
| `--cli` | Консольный режим: выполнение резервного копирования с выводом прогресса и логов в терминал. |
| `--silent` | Тихий консольный режим без интерактивных запросов с автозакрытием окна через 8 секунд после завершения. |
| `--hidden` | Полностью фоновый режим без окна (с иконкой в системном трее, если поддерживается средой). |
| `--no-clean` | Выполнить резервное копирование без автоматического удаления устаревших архивов. |
| `--lite` | Запуск графического интерфейса в облегчённом текстовом режиме (`LITE`). |

## Расположение файлов конфигурации и логов

Все рабочие файлы пользователя хранятся изолированно от папки с программой:
* `~/.backup_hgm/config.json` — основные настройки, история адресов серверов и журнал последних 25 операций.
* `~/.backup_hgm/.env` — резервное зашифрованное/изолированное хранилище токенов и PIN-кодов (`chmod 0600`), если системный `keyring` недоступен.
* `~/BackupHGM/` (по умолчанию) — каталог сохранения `.zip`-архивов, файлов `.sha256` и системного лога `backup.log`.
